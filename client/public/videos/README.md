# Video Files — Drop your MP4s here

Place your two clinic videos in this folder with EXACTLY these filenames:

  hero-bg.mp4       ← Video 1 (clinic busy scene — Hero section background)
  about-bg.mp4      ← Video 2 (Dr. Syed examining child — About section background)

The code in Hero.jsx and AboutDoctor.jsx references these exact paths:
  /videos/hero-bg.mp4
  /videos/about-bg.mp4

Recommended encoding settings for best performance:
  - Format:     H.264 MP4
  - Resolution: 1920×1080 (or 1280×720 minimum)
  - Bitrate:    2–4 Mbps (balance quality vs. load time)
  - Audio:      Strip audio (video is muted anyway)
  - Duration:   Loop-friendly (no abrupt cut at end)
